Listening for requests

Requests this page makes with fetch, XHR and WebSocket appear here as they happen. Reload the page to capture its startup calls.

Automate API work: chain calls, filter and loop over results, branch, and remember what was already handled. Run a flow now, on a schedule, or whenever this page makes a matching request — they keep working while Chrome is open, even with this page closed.

Settings

Kimi API key

Get one at platform.moonshot.ai — a key with a spend cap is wise. It is stored in this browser profile only (chrome.storage.local, never synced) and sent only to api.moonshot.ai.

Rate limits

Kimi counts every request against your per-minute limit as its input plus the max reply length, whatever the reply really uses. NetScope keeps both small and spaces requests out to stay under your tier, waiting a few seconds instead of failing. Your tier is shown at platform.kimi.ai/console; recharging raises it.

Your data

Move NetScope to another browser: export here, then import the file in NetScope there. The file holds your conversations and flows, which can include captured tokens and personal data — keep it private.

Shortcut

Alt+Shift+N opens or hides NetScope on the current page. Change it at chrome://extensions/shortcuts.
